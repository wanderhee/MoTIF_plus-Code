严格输出一个 JSON 对象，不要输出 Markdown、解释文字或代码块。

字段和允许值：
{
  "event_type": "无事件|交通事故|拥堵|施工|抛洒物|异常停车|行人闯入|清障|收费站|其他",
  "incident_level": "0|1|2|3",
  "event_description": "事件的详细自然语言描述",
  "scene_region": "左侧|中间|右侧|上方|下方|近距离|远距离|未知",
  "road_location": ["应急车道|行车道|超车道|正常路段|匝道|收费站|未知"],
  "affected_lanes": ["应急车道|行车道|超车道|无|未知"],
  "weather": "晴|阴|雨|雪|雾|霾|未知",
  "visibility": "1|2|3|null",
  "lighting": "白天|夜间|黄昏|人工照明|未知",
  "queue_present": true,
  "queue_overflow": false,
  "queue_count": 0,
  "impact": "0|1|2|3"
}

判断原则：
以视频中可见的车道占用、车辆排队、人员伤亡、道路封闭、通行能力和环境条件为准，不要只根据事件类型推断等级。事件类型严重不代表 incident_level 或 impact 一定高。

要求：
1. 只输出合法 JSON。
2. 不确定的字段填 "未知" 或 null，不要编造。

3. incident_level 用 0/1/2/3，表示事件本身的严重程度：
   0 = 无事件：未发生交通事件，交通流正常。
   1 = 轻微：事件存在，但未占用行车道或仅短暂占用；未形成车辆排队；车辆可正常通行或仅轻微减速；无人员伤亡、无车辆损坏、无道路封闭。
   2 = 一般：事件占用一条或多条车道（含应急车道），或形成短时排队；排队未超出摄像头范围；车辆需要减速、绕行或短时等待；无人员伤亡、无道路封闭、无火灾、无侧翻、无多车相撞。
   3 = 严重：出现任一情况：人员伤亡；多车相撞、侧翻、火灾；道路封闭或长时间无法通行；排队明显超出摄像头范围或长时间严重拥堵；现场存在二次事故风险且尚未受控。

4. impact 用 0/1/2/3，表示事件对交通的实际影响：
   0 = 无影响：无车道被占用，无排队，交通流正常。
   1 = 轻微影响：有车道被占用，但未形成排队；车辆可以绕行，通行基本正常。
   2 = 一般影响：有车道被占用并形成排队，但排队未超出摄像头范围；通行能力下降，车辆需要减速或绕行。
   3 = 严重影响：排队超出摄像头范围；或道路封闭、多车道受阻、人员伤亡，或存在二次事故风险。

5. visibility 用 1/2/3，根据画面中可观察到的能见度判断：
   1 = 低：远处车辆、车道线、路牌难以辨认；画面整体模糊或对比度低；雾、雨、雪、夜间光照不足等导致视距明显受限。
   2 = 中：远处目标部分可见但细节不清；轻雾、降雨、黄昏或光线一般，驾驶员需要更仔细辨认。
   3 = 高：远处车辆、车道线、路牌清晰可见；晴天、白天或照明良好的夜间，画面对比度正常。

6. queue_count 用整数；没有排队时填 0；无法判断时填 null。
7. affected_lanes 和 road_location 用数组；多个车道用多个元素。
8. event_description 用中文描述事件经过、参与对象、位置和影响。
